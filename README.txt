DEC Crane – Statik Site

Kurulum: Bu klasörün İÇİNDEKİ tüm dosyaları hostinginizin kök klasörüne yükleyin.
- Sayfa adresleri eski siteyle aynıdır (/en/marine-winches/ahc-winches/ vb.).
- İletişim formu send.php ile çalışır (PHP gerekli; GitHub Pages'te çalışmaz).
- Görseller WebP'ye çevrilip küçültülmüştür. Fontlar: Saira (başlık) + Inter (metin), /fonts içinde.
- Yerelde test için VS Code Live Server veya 'npx serve' kullanın.
