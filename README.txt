DEC Crane – Statik Site

Kurulum: Bu klasörün İÇİNDEKİ tüm dosyaları hostinginizin public_html (kök) klasörüne yükleyin.
- Sayfa adresleri eski siteyle aynıdır (/en/marine-winches/ahc-winches/ vb.), SEO bozulmaz.
- İletişim formu send.php ile çalışır (PHP gerekli). Alıcı adresi send.php içinde.
- Yerelde test için klasörü VS Code Live Server veya 'npx serve' ile açın (çift tıklayınca klasör linkleri çalışmaz).
- Font: assets/fonts içindeki Octosquares 'Trial' sürümüdür; canlıda lisanslı sürümle değiştirin.
